# PeepMD releases

Signed and notarized builds of [PeepMD](https://penpoint.dev), a macOS Quick
Look preview for Markdown files. Published by Penpoint.

This repository holds no code. It only hosts the release zips on the
[Releases](https://github.com/penpointdev/peepmd-releases/releases) page.

## Install

Install with Homebrew from the Penpoint tap:

```sh
brew install penpointdev/tap/peepmd
```

Then open PeepMD once so macOS registers the preview extension.

The tap is [penpointdev/homebrew-tap](https://github.com/penpointdev/homebrew-tap).
